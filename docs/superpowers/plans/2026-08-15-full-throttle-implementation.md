# Full Throttle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production-ready, tactile 3D turbofan exhibit at `/exhibits/full-throttle` and make the lobby registry-driven with only Apollo and Full Throttle visible.

**Architecture:** A server-rendered exhibit page supplies the complete semantic story and dynamically enhances into one persistent React Three Fiber engine. Pure state modules drive the exploded view, airflow scrubber, and throttle so WebGL, SVG fallback, keyboard navigation, and tests consume the same state. A typed lobby registry controls visibility without removing any exhibit routes.

**Tech Stack:** Next.js 16.3 App Router, React 19, TypeScript, CSS Modules, React Three Fiber, Drei, Three.js, GSAP/ScrollTrigger, Lenis, Web Audio, Blender/GLB, Zod, Vitest, Testing Library, Playwright.

## Global Constraints

- Start from local `main` on branch `codex/full-throttle-exhibit`.
- Do not commit or push; replace commit steps with local diff and verification checkpoints.
- Read the relevant local Next.js 16.3 guides under `node_modules/next/dist/docs/` before modifying application code.
- Preserve `/exhibits/living-atlas` and all anatomy implementation; hide it only through registry status.
- Render only `/exhibits/thirteen-minutes` and `/exhibits/full-throttle` on the homepage.
- Build seven independent named engine groups: `fan`, `lp_compressor`, `hp_compressor`, `combustor`, `hp_turbine`, `lp_turbine`, `nozzle`.
- Keep all factual UI values relative unless an authoritative source supports an absolute value.
- Respect `prefers-reduced-motion`, keyboard access, touch access, no-JavaScript reading order, and WebGL failure.
- Mute audio by default and never require audio for comprehension.
- Target `public/models/turbofan-parts.glb` below 1.8 MB and its poster below 250 KB.
